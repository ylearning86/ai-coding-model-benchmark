## 再採点ルール

- CodeQLのCritical／Highはセキュリティ点から減点する。
- GitHub Code Qualityの重大なReliability／Maintainability issueはコード点から減点する。
- 同一原因を複数ツールが検出した場合は重複減点しない。
- 誤検知は根拠を記録し、減点しない。
- 人によるブラインドデザイン評価を追加する場合は、AI評価との平均または別表にする。
