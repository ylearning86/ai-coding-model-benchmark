# PRISMFALL

**光のブロックを積み上げろ。**

ブラウザーだけで遊べる、オリジナルの落ちものブロックパズルです。10 列 × 20 行のフィールド、7 種類の 4 連ブロック、ホールド／ゴースト／ネクスト、スコア・レベル・ライン数、ローカルランキングまでを含んだ完成品として動作します。

外部サーバー・外部 API・有料サービスは一切使用しません。`npm install` の後はオフラインで動作し、記録はブラウザーの `localStorage` にのみ保存されます。

---

## クイックスタート

```bash
npm install     # 依存関係の取得（初回のみ）
npm run dev     # 開発サーバー起動 → http://localhost:5173/
```

### すべてのコマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | Vite 開発サーバー（HMR 付き）を起動します。 |
| `npm run build` | 型チェック（`tsc --noEmit`）の後に `dist/` へ本番ビルドします。 |
| `npm run preview` | ビルド済みの `dist/` をローカル配信して最終確認します。 |
| `npm run lint` | ESLint（flat config・TypeScript 対応）を実行します。 |
| `npm run test` | Vitest でゲームロジックの自動テストを 1 回実行します。 |
| `npm run test:watch` | 監視モードでテストを実行します。 |
| `npm run verify` | **lint → test → build** を通しで実行します（提出前の確認用）。 |

> ビルド出力は相対パス（`base: './'`）なので、`dist/` をそのまま任意の静的ホスティングや `file://` 配下に置いても動作します。

## 技術選定と理由

| 採用 | 理由 |
| --- | --- |
| **TypeScript（strict）** | 盤面・ピース・回転・スコアといった状態を型で固定でき、リファクタ時の破壊を検出できます。`strict` に加えて `noUnusedLocals` / `noImplicitOverride` / `noFallthroughCasesInSwitch` を有効化しています。 |
| **Vite 5** | ゼロ設定に近い ESM 開発サーバーと最適化ビルドを両立します。**Vite 7 系は Node.js `^20.19 \|\| >=22.12` を要求する**ため、より広い Node.js 20 系で動く **Vite 5 系に固定**しました。 |
| **Canvas 2D（描画ライブラリなし）** | 毎フレーム 200 セル規模を再描画する用途では、DOM 要素を大量に持つより Canvas の方が安定して 60fps を維持できます。ゴーストやロック時のフラッシュなど、ピクセル単位の演出も素直に書けます。 |
| **ランタイム依存ゼロ** | React などの UI フレームワークを入れても、本質である「盤面の状態遷移」は自作になります。依存を持たないことでバンドルが小さく、供給網リスクと将来の破壊的変更を避けられます（`package.json` の `dependencies` は空です）。 |
| **Vitest 2** | Vite と設定を共有できるため、テスト専用のビルド設定が不要です。ゲームコアは DOM に依存しないので `environment: 'node'` で高速に回せます。 |
| **ESLint 9（flat config）+ typescript-eslint** | 現行の推奨構成です。`consistent-type-imports` や `eqeqeq` などを有効にして記述を揃えています。 |

### アーキテクチャ

```
src/
  game/          純粋なゲームコア（DOM に一切触れない → そのまま単体テスト可能）
    constants.ts   盤面サイズ・各種タイミング定数
    pieces.ts      7 種のピース定義、回転形状、SRS 準拠のキックテーブル
    board.ts       盤面の生成・衝突判定・マージ・ライン検出・落下距離
    rng.ts         シード付き乱数（mulberry32）と 7-bag ランダマイザー
    scoring.ts     レベル曲線、重力間隔、加点・コンボ・Back-to-Back 計算
    engine.ts      状態機械（重力／ロックディレイ／ホールド／スピン判定／イベント発行）
  ui/            描画・入力・永続化（ブラウザー依存）
    theme.ts       ピース配色
    renderer.ts    盤面プレビューの Canvas 描画
    effects.ts     ライン消去フラッシュ・ドロップ軌跡・シェイク
    input.ts       キーボード（DAS/ARR）、タッチパッド、スワイプ操作
    hud.ts         スコア表示・オーバーレイ・ランキング DOM（textContent のみ）
    ranking.ts     localStorage への保存と、読み出し値の検証・正規化
  main.ts        上記を束ねる requestAnimationFrame ループ
tests/           Vitest によるゲームロジックのテスト
```

`Engine` は入力に応じて `GameEvent`（`spawn` / `lock` / `clear` / `levelup` / `gameover` など）を返し、UI 側はそのイベントを見て演出やトーストを出します。**描画層を差し替えてもゲームの挙動は変わらない**構造です。

## 遊び方

ニックネームを入れて **ゲーム開始**。落ちてくるブロックを積み、横 1 行をすべて埋めると消えます。消したライン数でレベルが上がり、落下が速くなります。ブロックが上端を越えるとゲームオーバーです。

盤面には **ゴースト**（落下先の輪郭）が常に表示されるので、初見でも着地位置が分かります。右側に **NEXT 3 手**、左側に **HOLD** が並びます。

### キーボード

| 操作 | キー |
| --- | --- |
| 左右移動 | `←` `→` / `A` `D` |
| ソフトドロップ | `↓` / `S` |
| ハードドロップ | `Space` |
| 右回転 | `↑` / `X` / `W` |
| 左回転 | `Z` / `Ctrl` |
| ホールド | `C` / `Shift` |
| 一時停止・再開 | `P` / `Esc` |
| リスタート | `R` |
| 決定（開始・再開） | `Enter` |

長押しには DAS 150ms / ARR 40ms を実装しており、素早い横移動ができます。

### タッチ操作（スマートフォン・タブレット）

- 画面下部に **専用パッド**（左 / 右 / 回転 / ホールド / ソフトドロップ / ハードドロップ / 一時停止）が自動で表示されます。
- 盤面上の **ジェスチャー** も使えます。
  - 左右にドラッグ … 横移動
  - 下へゆっくりドラッグ … ソフトドロップ
  - 下へ素早くスワイプ … ハードドロップ
  - タップ … 右回転

`touch-action: none` と `viewport-fit=cover` を指定し、スクロールやピンチによる誤操作・ノッチ切れを防いでいます。

## 実装している要素

- 10 × 20 のプレイフィールドと 7 種類のピース（I / J / L / O / S / T / Z）
- 左右移動・左右回転・ソフトドロップ・ハードドロップ
- **SRS 準拠のウォールキック**（壁際・床際でも自然に回る）
- ネクスト 3 手表示、ホールド（1 手につき 1 回）、着地点ゴースト
- 7-bag ランダマイザー（同じピースが極端に偏らない）
- ロックディレイ（500ms・最大 15 回リセット）で細かい滑り込みが可能
- ライン消去・スコア・レベル・消去ライン数の表示
- コンボ、Back-to-Back（×1.5）、**T スピン判定**（ミニ含む）
- 一時停止・再開・リスタート・ゲームオーバー、タブ非表示時の自動一時停止
- ニックネーム入力とローカルランキング（上位 10 件、順位ハイライト、消去ボタン）
- デスクトップ / モバイル両対応のレスポンシブレイアウト（縦長画面・横向き低い画面も個別調整）
- `prefers-reduced-motion` に応じた演出の抑制

### 演出の方針

アニメーションは「操作の邪魔をせず、状態理解を助ける」ことだけを目的にしています。ライン消去は 320ms のフラッシュで**何行消えたかを目で追える**ようにし、ハードドロップは軌跡と短いシェイクで**着地の手応え**を返します。いずれも入力を受け付けたまま進行し、`prefers-reduced-motion: reduce` の環境では自動的に無効化されます。

## 安全性への配慮

- **DOM への挿入は `textContent` のみ。** `innerHTML` / `insertAdjacentHTML` / `eval` は一切使用していません。ニックネームに `<script>` を入れても、そのままの文字列として表示されます。
- **入力値の正規化。** ニックネームは制御文字・ゼロ幅文字を除去し、空白を畳み、12 文字に切り詰めます。空になった場合は `PLAYER` を使います。
- **保存データを信用しない。** `localStorage` の内容は改ざんされうる外部入力として扱い、JSON パース失敗・配列以外・型不正・過大な数値をすべて弾いて上限値にクランプします（スコア 99,999,999 / ライン 999,999 / レベル 99）。壊れていれば空のランキングとして扱います。
- **ストレージ不可の環境でも落ちない。** プライベートモードなどで `localStorage` が使えない場合はメモリ上のフォールバックに切り替わり、例外はすべて握りつぶされます。
- **外部通信なし。** フォント・画像・スクリプトを含め、外部ドメインへのリクエストは行いません。アイコンはインライン SVG です。
- **CSP（`index.html` の `<meta http-equiv="Content-Security-Policy">`）。**
  `default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self' ws: wss:; font-src 'self'; base-uri 'none'; form-action 'none'`
  トレードオフとして、**開発サーバー（HMR）を動かすために `style-src` に `'unsafe-inline'`、`connect-src` に `ws:` / `wss:` を許可**しています。Vite が開発時にスタイルをインラインで注入し、WebSocket で更新を配信するためです。`script-src 'self'` は開発時も維持しているため、インラインスクリプトの実行は常に禁止されています。本番配信時にこの 2 つを外して運用することも可能です。なお `frame-ancestors` は `<meta>` 経由では無視される仕様のため含めていません。埋め込みを禁止する場合は HTTP レスポンスヘッダー側で指定してください。

## テスト

```bash
npm run test
```

ゲームコア（`src/game/**`）と保存層（`src/ui/ranking.ts`）を対象にしています。UI 依存を排したおかげで、ブラウザーを起動せずロジック全体を検証できます。

| ファイル | 検証内容 |
| --- | --- |
| `tests/board.test.ts` | 盤面生成、複製の独立性、壁・床・隠し行の判定、衝突、非破壊マージ、full 行検出、行削除と落下、落下距離、積み上げ高さ |
| `tests/pieces.test.ts` | 7 種 × 4 回転がすべて 4 セルであること、外接矩形、4 回転で元に戻ること、O の回転不変、初期位置がフィールド内、SRS キック候補の具体値と逆回転の対称性 |
| `tests/rng.test.ts` | 同一シードの再現性、値域、シード差、7-bag が 7 種を必ず 1 回ずつ含むこと、同じピースが 3 連続しないこと |
| `tests/scoring.test.ts` | レベル境界と上限、重力間隔の単調減少と下限、基本点、T スピン点、Back-to-Back ×1.5、コンボ加点、表示ラベル、ドロップ加点 |
| `tests/engine.test.ts` | 起動・シード再現・一時停止中の入力無効・リスタート・ゲームオーバー、移動と壁、重力、ソフト／ハードドロップ加点、ゴースト、ロックディレイ、回転とウォールキック、ホールド制約、ライン消去と行の詰め、レベルアップ、コンボ遷移、T スピン成立条件、ビューのスナップショット |
| `tests/ranking.test.ts` | 名前の無害化、保存データの検証とクランプ、並び順、1 起点の順位、上位 10 件の維持、圏外時の `-1`、壊れた JSON の無視、消去、ニックネームの往復、例外を投げるストレージへの耐性 |

## オリジナリティについて

**PRISMFALL** は本作のためのオリジナル名称です。既存作品のロゴ・書体・配色・効果音・音楽・画像・固有のブランド表現は使用しておらず、UI（プリズムを模したシンボル、オーロラ調の背景、ガラス質のパネル）とすべてのコードは本リポジトリ向けに書き下ろしています。回転規則は公開されている一般的な回転システムの仕様に沿って実装したものです。

## 動作環境

Node.js 20.17 以上（開発時）。実行はモダンブラウザー（Chromium / Firefox / Safari の最新版）を想定しています。
