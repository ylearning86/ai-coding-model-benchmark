# LUMEN FALL

光の信号をモチーフにした、ブラウザーで遊べる10列×20行の落ちものブロックパズルです。

## 実行方法

Node.js 20以降を推奨します。外部依存関係はありません。

```powershell
npm run verify
npx serve dist
```

または `index.html` をブラウザーで直接開いても遊べます。ローカルサーバーを使う場合は、任意の静的ファイルサーバーでプロジェクトルートまたは `dist` を配信してください。

## 技術選定

- Vanilla JavaScript + Canvas: 高頻度の盤面描画を軽量に保ち、依存なしで再現可能にするため
- CSS Grid / カスタムプロパティ: デスクトップとモバイルで盤面比率を保つため
- Node.js標準テストランナー: 外部パッケージなしでゲームロジックを検証するため
- localStorage: ニックネームと上位5件のスコアを端末内だけに保存するため

ランキング表示は `textContent` とDOM APIのみを使い、保存値は型・範囲を検証しています。外部通信やHTML文字列挿入は行いません。

## 検証

`npm run verify` でビルド、構文チェック、12件のゲームロジックテストを順に実行します。
