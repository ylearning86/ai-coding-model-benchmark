# CASCADE BLOCKS

ブラウザーで遊べるオリジナルの落ちものブロックパズルです。10 列 x 20 行のフィールドに 7 種類の
4 ブロックピースが落ちてきます。横一列をそろえて消し、レベルを上げながらハイスコアを狙います。

## 実行方法

```bash
npm install      # 依存関係のインストール（初回のみ）
npm run dev      # 開発サーバー（表示された http://localhost:5173 を開く）
npm run build    # 型チェック + 本番ビルド（dist/）
npm run preview  # ビルド結果の確認
npm run lint     # ESLint
npm test         # Vitest（ゲームロジックの単体テスト）
npm run verify   # lint + build + test をまとめて実行
```

外部サービスへの通信はありません。記録は `localStorage` にのみ保存されます。

## 操作方法

| 操作 | キーボード | タッチ / マウス |
| --- | --- | --- |
| 左右移動 | ← → | 画面下のボタン、盤面の左右スワイプ |
| 回転 | ↑ / X（逆回転 Z） | 「回転」ボタン、盤面のタップ |
| ソフトドロップ | ↓ | 「ソフト」ボタン |
| ハードドロップ | Space | 「ハード」ボタン、盤面の下スワイプ |
| ホールド | C | 「ホールド」ボタン |
| 一時停止 / 再開 | P / Esc | 「一時停止」ボタン |
| リスタート | R | 「リスタート」ボタン |

スコアは 1/2/3/4 ライン消去で 100/300/500/800 点 x レベル、ソフトドロップ 1 点/マス、
ハードドロップ 2 点/マスです。10 ラインごとにレベルが上がり落下が速くなります。

## 技術選定の理由

- **TypeScript + Vite**: ビルド・開発サーバー・本番バンドルが 1 つで完結し、追加設定なしで
  高速に立ち上がるため。型があることでゲーム状態の取り違えを実装時に検出できます。
- **Vitest**: Vite と設定を共有でき、追加のトランスパイル設定なしで TypeScript のテストを実行できるため。
- **Canvas 2D（フレームワークなし）**: 毎フレーム更新する描画では DOM 差分更新よりも
  素直で軽量です。UI パネルは通常の HTML/CSS のままにして、レスポンシブは CSS Grid に任せています。
- **ロジックと描画の分離**: `src/engine.ts` は DOM に依存しない純粋なゲームロジックで、
  そのまま単体テストできます。`src/main.ts` が描画・入力・保存を担当します。
- **依存を最小化**: ランタイム依存はゼロ（devDependencies のみ）で、ローカルで再現しやすくしています。

## 安全性

- 文字列はすべて `textContent` で描画し、`innerHTML` は使用していません。
- ニックネームは制御文字を除去し 12 文字に丸めてから保存・表示します。
- `localStorage` の読み込みは JSON を検証し、型が合わない要素は破棄します（`parseRanking`）。
- ストレージが使えない環境でも例外で停止せず、ゲーム自体は動作します。
- 外部 CDN・フォント・API を一切参照しません。

## テスト

`src/engine.test.ts` に 16 ケース。盤面初期化、7 種バッグ、移動と壁判定、壁際回転のキック、
ソフト/ハードドロップと加点、ゴースト、ホールド制限、一時停止、自然落下、1/4 ライン消去のスコア、
レベルアップ、ゲームオーバー、入力値の無害化、壊れた保存データの破棄、ランキングの整列を検証します。

## 既知の未完成点

- 回転は簡易キック（0, -1, +1, -2, +2 の水平ずらし）のみで、SRS のような詳細な回転規則や
  床キックは実装していません（課題の指示により意図的に除外）。
- キーボードの左右移動は OS のキーリピートに依存しており、DAS/ARR の調整はできません。
- 効果音、T スピン、Back-to-Back、コンボなどの拡張要素は要件外のため未実装です。
- ランキングはブラウザーごとのローカル保存で、端末間の共有はできません。
- 画面回転直後などにキャンバスの再計算が 1 フレーム遅れることがあります（次の描画で解消します）。
