# Block Puzzle (落ちものブロックパズル)

高品質なブラウザー用ブロックパズルゲームです。

## 実行方法

### 開発サーバーの起動
```bash
npm install
npm run dev
```

### ビルド
```bash
npm run build
```

### テスト実行
```bash
npm run test
```

## 技術選定理由

- **React 18 + TypeScript**: 安全な型定義とコンポーネント指向の開発による高い生産性とメンテナンス性。
- **HTML5 Canvas**: 高速かつレスポンシブな盤面描画とゴースト表示の滑らかなレンダリング。
- **Vite**: 高速なビルドと開発環境の提供。
- **Vitest**: 軽量で高速なゲームロジックの単位テスト環境。
